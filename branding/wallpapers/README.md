# OBLinux Wallpapers

## Approved variants

- `oblinux-horizon-branded-3840x2160.jpg`: default OBLinux wallpaper
- `oblinux-horizon-clean-3840x2160.jpg`: alternate unbranded wallpaper

Both wallpapers use the approved Obsidian Horizon palette and are 3840 by 2160
pixels. The branded variant places the authoritative reversed wordmark at 12%
of canvas width, inset 4% from the right and bottom edges, at 72% opacity.

The clean wallpaper is the visual master. The branded variant is assembled by
`../source/build_wallpapers.py`; the logo is not redrawn by image generation.
