# System Branding Assets

These assets support installed-system identity surfaces introduced in Build
006, including GNOME About, installed GRUB, Plymouth, and the default account
avatar used for newly created users.

The Plymouth logo reuses the transparent approved OBLinux Calamares symbol.
The small progress textures use Obsidian Horizon palette colors and are
generated by `../source/build_system_assets.py`.

`oblinux-default-avatar.svg` is a neutral user silhouette rather than a
product mark. Its Obsidian Horizon field and cyan accents keep the login and
lock surfaces cohesive without representing a user as the OBLinux logo.
