# System Branding Assets

These assets support installed-system identity surfaces introduced in Build
006, including GNOME About, installed GRUB, and Plymouth.

The Plymouth logo derives from the approved OBLinux installer icon. The small
progress textures use Obsidian Horizon palette colors and are generated by
`../source/build_system_assets.py`.
