## GitHub release-size finding

GitHub Releases requires each individual asset to be smaller than 2 GiB
(2,147,483,648 bytes). Build 002 is only 10,184,704 bytes, approximately
9.7 MiB, below the limit.

The project should assume that the next meaningful package or branding addition
will cross the limit. VM testing should proceed without changing package
composition. Before public artifact publishing, OBLinux must either reduce the
image deliberately or use alternate artifact hosting.
