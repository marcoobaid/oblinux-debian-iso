## Static verification

The following checks passed:

- live-build reported `Build completed successfully`.
- The ISO contains GRUB BIOS and UEFI El Torito boot entries.
- The image retains its protective MBR and GPT hybrid layout.
- Calamares and Debian's Calamares settings are in the package manifest.
- UEFI GRUB, signed GRUB, shim, and `efibootmgr` are present.
- The `Install Debian` launcher is present and invokes
  `calamares-install-debian`.
- Calamares is configured as a normal installer rather than OEM or post-install
  setup.
- The `unpackfs` module reads the live SquashFS from
  `/run/live/medium/live/filesystem.squashfs`.
- The artifact checksum verifies successfully.

Static verification does not prove that partitioning, copying, user creation,
bootloader installation, cleanup, or first boot will succeed.

## GitHub release-size finding

GitHub Releases requires each individual asset to be smaller than 2 GiB
(2,147,483,648 bytes). Build 002 is only 10,184,704 bytes, approximately
9.7 MiB, below the limit.

The project should assume that the next meaningful package or branding addition
will cross the limit. VM testing should proceed without changing package
composition. Before public artifact publishing, OBLinux must either reduce the
image deliberately or use alternate artifact hosting.
