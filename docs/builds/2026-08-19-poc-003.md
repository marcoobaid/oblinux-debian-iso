## GitHub release-size finding

GitHub Releases requires each individual asset to be smaller than 2 GiB
(2,147,483,648 bytes). Build 003 is 10,180,608 bytes, approximately 9.7 MiB,
below that limit. The remaining margin is too small for planned application and
branding additions, so alternate artifact hosting or deliberate image-size
reduction remains necessary before public releases.
