## GitHub release-size finding

GitHub Releases requires each individual asset to be smaller than 2 GiB
(2,147,483,648 bytes). Build 004 is 8,939,520 bytes, approximately 8.5 MiB,
below that limit. Further additions can exceed the limit, so the project must
reduce the image or select another artifact-hosting approach before relying on
GitHub Releases.
