## Build interruption and recovery

The first invocation stopped in the new ownership-validation hook after package
installation. A shell quoting error made a literal backslash the first item in
the path list. The hook correctly failed before producing an ISO.

Commit `0a91fb4` removed the unintended character. All six ownership and content
conditions then passed against the preserved chroot. Running `lb build` again
resumed from the incomplete hook stage and completed successfully; cleaning or
repeating the completed package work was unnecessary.

## GitHub release-size finding

GitHub Releases requires each individual asset to be smaller than 2 GiB
(2,147,483,648 bytes). Build 005 is 8,724,480 bytes, approximately 8.3 MiB,
below that limit. The project must reduce the image or choose another hosting
approach before adding materially larger release content.
