# R5 v1.0.1 runtime remediation round 2

This build corrects downstream activation and composition defects reported
against the first R5 v1.0.1 ISO while retaining the immutable Brand Master pin.

## Changes

- Set installed GRUB's supported `GRUB_BACKGROUND` to the package-owned R5
  background so Debian `desktop-base` cannot replace it during GRUB generation.
- Enable Calamares' documented welcome-image scaling for the 1100-pixel R5
  lockup while preserving the corrected sidebar palette.
- Replace only the superseded lower-right Obsidian Horizon logo with the
  authoritative R5 v1.0.1 white lockup.
- Record the static Plymouth dots and undersized symbol as shared-theme defects
  requiring Brand Master v1.0.2 rather than creating a Debian-only fork.
