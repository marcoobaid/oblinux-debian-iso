## Package findings

Debian's `task-gnome-desktop` and its recommended dependencies pulled in more of
the planned workstation than the explicit package list suggests:

- LibreOffice Writer, Calc, Impress, Draw, and supporting integration are
  present.
- CUPS daemon, client, filters, browsing, and core drivers are present.
- BlueZ, UFW, Flatpak, Zsh, and Starship are not present and remain future
  explicit choices.

This illustrates an important Debian packaging concept: a task package selects
a curated desktop and its dependency graph. Final contents must be measured
from the generated package manifest rather than inferred only from OBLinux's
short explicit package list.

## Release-engineering finding

GitHub Releases requires each individual release asset to be smaller than
2 GiB (2,147,483,648 bytes). This ISO is only 105,512,960 bytes, approximately
100.6 MiB, below that ceiling. Additional packages may push future images over
the limit.

No package-removal decision is required before VM testing. After functionality
is verified, package composition and compression can be reviewed deliberately.
