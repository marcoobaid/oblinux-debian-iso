## Finding: Calamares initial timezone selection

The live system correctly used `America/Chicago`, but the Calamares location
page initially selected `America/New_York`. Selecting Chicago manually resulted
in the installed system retaining `America/Chicago` correctly.

This is an initial-selection usability issue rather than a clock-sync or
installation failure. A future OBLinux Calamares configuration should prefer
the live system's current timezone while keeping the choice editable.
