insufficient contrast against the dark window background. The symbol geometry,
cyan bridge, operating-system identity, and corrected size remain intact, but
the letters appear too dull.

This is a presentation-only finding. A future treatment must support light and
dark appearances without changing the approved geometry or concealing the
Debian base identity.
