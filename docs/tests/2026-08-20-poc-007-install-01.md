## Live-media verification

The ISO booted successfully and retained the branded GRUB presentation. GNOME
reached the live desktop and the system remained functional.

GNOME Settings About displayed the correct OBLinux symbol and
`OBLinux Proof of Concept (Debian 13)`. The symbol was substantially too large,
dominated the page, and pushed the system information downward.

Calamares displayed its corrected symbol cleanly. The transparent background,
placement, proportions, sidebar contrast, and spacing passed visual review.
There were no white corners, borders, tiles, stretching, or clipping.

The separate installer launcher icon in GNOME's Dash retained white corner
artifacts. Correcting Calamares' product logo did not update the icon source
used by the desktop launcher.

The live boot did not show a graphical Plymouth presentation. Plymouth services
started, but verbose kernel and systemd console output remained visible. This
finding is limited to live-media boot; installed-system Plymouth passed.

## Installation and installed-system verification

Installation completed and the installed system remained functional. The
following checks passed:

- Installed GRUB retained the approved OBLinux theme and concise labels.
- Installed Plymouth displayed the transparent, proportional OBLinux symbol,
  gradient background, and progress indicator without white corners or a tile.
- GRUB and Plymouth branding persisted after regeneration and reboot.
- GNOME Settings About displayed the correct OBLinux symbol and operating-system
  name.
- The local GNOME vendor-logo diversion was active.
- Debian's original vendor emblem was preserved as
  `emblem-vendor.svg.distrib`.
- The installed timezone was `America/Chicago`.
- System clock synchronization was active and the hardware clock remained in
  UTC.
- No additional functional issues were observed during testing.

The GNOME About symbol remained excessively large on the installed system,
confirming that the sizing defect is in the shared vendor-emblem presentation
rather than the live session.

## Open presentation findings

### Live-media Plymouth

The live boot falls back to verbose console output even though Plymouth starts.
The live boot parameters, graphics handoff, and live initramfs theme activation
need investigation without changing the working installed-system Plymouth
path.

### Installer launcher icon

The GNOME Dash launcher uses a separate icon source that still contains the old
opaque white corners. It must be located and replaced with an appropriate
transparent application-icon asset.

### GNOME About symbol size

GNOME's fixed distributor-logo presentation renders the tightly framed symbol
too large. The active vendor SVG should retain the approved geometry on a
larger transparent canvas so the visible mark has balanced whitespace within
GNOME's fixed display area.

## Conclusion

Build 007 resolves GNOME's incorrect Debian identity and the Calamares and
installed-Plymouth transparency defects. Installation and tested system
functions passed. Three focused visual follow-ups remain: enable graphical
Plymouth for live-media boot, replace the separate Dash launcher icon, and
reduce the apparent GNOME About symbol size.
