## Finding: live-session lock during installation

The GNOME live session automatically locked while Calamares was unattended.
Although the documented Debian live password restored access and installation
completed, requiring a password during installation is a poor and potentially
confusing user experience.

A later OBLinux image must disable automatic screen locking and automatic
suspend for the live account. The installed user's normal power and privacy
defaults must remain unaffected.

## Finding: four-to-five-minute installed boot

Both the legacy-BIOS installation and this UEFI installation reportedly spend
approximately four to five minutes between GRUB/initramfs startup and the GDM
login screen. The system is operational after the delay.

This duration is abnormal even for a modest VM and should not be attributed to
low resources without evidence. Likely categories include a device or mount
timeout, resume-device wait, wait-online service, firmware issue, or VirtualBox
graphics configuration. Systemd and kernel timing must identify the delayed
stage before any fix is selected.
