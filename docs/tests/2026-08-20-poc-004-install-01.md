## Finding: neutral live-session timezone

The live session reported `Etc/UTC` with an active, synchronized NTP service.
The installed system reported the correct timezone after the selection made in
Calamares.

UTC is a safe portable default for an image used in multiple regions; OBLinux
should not hardcode `America/Chicago` for every user. A later usability review
may evaluate optional network-based timezone detection or initializing
Calamares from a detected timezone while keeping the choice explicit and
editable. This observation does not block Build 004 acceptance.

Obsidian Horizon wallpaper integration is accepted as the baseline for further
OBLinux branding work.
