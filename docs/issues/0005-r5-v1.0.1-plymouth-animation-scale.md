# R5 v1.0.1 Plymouth animation and symbol scale

Status: upstream Brand Master correction required

## Observation

The R5 v1.0.1 Plymouth theme displays its five idle dots, but runtime testing
reported no visible active-dot animation. The centered product symbol also
renders at 192 by 192 pixels and is approximately two-thirds of the desired
visual size.

The Debian integration installs the pinned `oblinux-branding` package, selects
its `oblinux` Plymouth theme, and regenerates every installed initramfs. Static
inspection confirms that the generated image contains the package-owned
`oblinux.script`, `dot.png`, `dot-white.png`, and 192 by 192 `symbol.png`
unchanged. There is no supported Plymouth configuration key outside the theme
for either animation behavior or image scale.

## Ownership decision

Both defects are inside the shared R5 Plymouth implementation and must not be
forked in the Debian edition. A downstream edit would alter package-owned
shared artwork or script behavior and would immediately diverge from the Brand
Master release.

## Exact Brand Master v1.0.2 requirement

Brand Master v1.0.2 should:

1. replace or correct the active-dot implementation so one orange dot visibly
   advances across the five white positions during real Plymouth refreshes;
2. display the existing symbol geometry at approximately 1.5 times the v1.0.1
   size (target 288 by 288 pixels instead of 192 by 192), keeping it centered
   and preserving all master paths, colors, and proportions;
3. retain a safe fallback when animation is unavailable; and
4. include a real boot or `plymouthd` runtime test proving that multiple
   animation frames are visible, plus common-resolution checks for the larger
   symbol.

Once an immutable corrected release exists, this repository should bump its
Brand Master lock and package version, rebuild the ISO, inspect both initramfs
payloads, and repeat live and installed boot testing.
